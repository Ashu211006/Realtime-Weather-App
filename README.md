# Realtime Weather App

A responsive React weather application that displays live current weather and a five-day forecast for any city.

## Tech Stack

React, Vite, Material UI, CSS, OpenWeather API

## Features

- Search weather by city name
- Current temperature and weather condition
- Humidity, wind speed, pressure, and feels-like temperature
- Five-day forecast
- Responsive design

## Run Locally

```bash
npm install
npm run dev
